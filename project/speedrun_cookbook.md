# Speedrun cookbook

This cookbook is a generic checklist for setting up an RC car for speedruns. It does not refer to the specific Carten project. Work through the items before a speedrun and check off each completed item.

## Chassis

### Suspension
* [ ] Stiffen the dampers with thick shock oil.
* [ ] Shorten the spring travel.

### Drivetrain
* [ ] Install a spool in the front.
* [ ] Fill the rear differential with thick oil, but not excessively thick.
* [ ] For small-scale speedruns: use a belt-driven chassis where possible to avoid torque steer.

### Suspension geometry
* [ ] Set approximately 2 degrees of toe-in at the rear.
* [ ] Set 0 degrees of camber at the front and rear.

### Ride height and weight distribution
* [ ] Lower the chassis as far as possible.
* [ ] Set the front lower than the rear.
* [ ] Make the car slightly heavier in the front.
* [ ] Distribute the weight equally between the left and right side.
* [ ] Check the weight of the electronic components, in particular the battery, before purchase.

### Assembly
* [ ] Remove parts that have no function in a speedrun, such as the sway bars.
* [ ] Use threadlocker on all metal-on-metal screw connections.
* [ ] Check that the steering is assembled precisely and moves without resistance: with the servo disconnected, the steering parts must fall freely under their own weight.

## Tires
* [ ] Use foam rubber tires.
* [ ] Use tires as wide as possible.

## Body
* [ ] Mount an aerodynamic front and rear wing to generate downforce.
* [ ] Leave the body unpainted so that a quick technical inspection is possible at any time.

## Remote control and servo
* [ ] Use a precise, high-quality digital servo.
* [ ] Use a remote control with high precision (e.g., with hall-effect sensors).
* [ ] Adjust the dual rate (D/R) and the throttle and steering curves to the car and the track.
* [ ] You need to install a Gyro. Carefully test the correct Gyro gain setting.

## Environment
* [ ] Check that the track is dry and clean.
* [ ] Check that there is little or no wind.

## Motor and ESC
Contrary to common opinion, the motor and ESC are the least critical part of a speedrun setup. Prioritize the budget for the chassis, the tires, and the control components.
